# InstaSave Android

An Android app project for working with public Instagram reel and post links.

## Current progress

- [x] Android project structure
- [x] First InstaSave screen
- [x] Instagram link format check
- [x] GitHub Actions APK build workflow
- [ ] Implement permitted public-media download flow
- [ ] Test APK on Android devices

## Build

GitHub Actions builds a debug APK whenever code is pushed to the `main` branch. You can also start a build manually from the **Actions** tab using **Build InstaSave APK**.

When a build succeeds, download the `instasave-debug-apk` artifact from that workflow run.

## Responsible use

Use InstaSave only for content you own or have permission to save. The app is not affiliated with Instagram or Meta.
